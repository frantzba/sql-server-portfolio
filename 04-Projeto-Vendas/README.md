# Projeto de Vendas

Este projeto simula um sistema de vendas contendo:

- Clientes
- Produtos
- Pedidos
- Itens de pedidos

## Objetivo
Praticar modelagem de dados e consultas SQL aplicadas a cenários reais.

## Scripts
- Criação do banco
- Criação de tabelas
- Inserção de dados
- Consultas
- Relatórios
