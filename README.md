# Projeto SQL Server – Controle de Clientes e Pedidos

## 📌 Objetivo
Projeto prático para treinar conceitos fundamentais de SQL Server:
- Criação de tabelas
- Inserção de dados
- SELECT
- INNER JOIN
- WHERE
- GROUP BY
- HAVING

---

## 🗂 Estrutura do Projeto

- 01-Estrutura.sql → Criação das tabelas
- 02-Inserts.sql → Inserção de dados
- 03-Consultas-Basicas.sql → SELECT e JOIN
- 04-Consultas-Where.sql → Filtros
- 05-Consultas-GroupBy.sql → Agrupamentos
